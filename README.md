# Cycle Shop Sales Management Dashboard

A full-stack sales and inventory management dashboard for a cycle shop built with React, Vite, Tailwind CSS, Express, and PostgreSQL (Neon).

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Aswath24/cycle-shop)

## Features
- **Dashboard**: High-level sales and profit/loss metrics.
- **Sale Entry**: Auto-calculated Selling Price, GST, Discounts, and Profit/Loss.
- **Inventory Management**: Track available stock, unit buying prices, and suppliers.
- **Reporting**: Monthly breakdowns and downloadable sales summaries.

## Deployment Instructions
1. Click the **Deploy to Render** button above (or open [Render](https://dashboard.render.com/select-repo?type=web)).
2. Connect your GitHub account and select this repository (`Aswath24/cycle-shop`).
3. Set the `DATABASE_URL` environment variable to your Neon PostgreSQL connection string.
4. Click **Apply / Deploy**.

Whenever changes are pushed to `main`, Render will automatically rebuild and redeploy your live site!
